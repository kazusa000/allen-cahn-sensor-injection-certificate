# R5 消融矩阵

## 目的

R5-E/R5-F 已经验证了 GPU 训练入口、独立回放和固定信息边界。这里把影响结论的设计因素
逐项拿掉，回答两个问题：

1. 在线校正误差是否依赖固定物理增益、状态质量范数和观测方向约束；
2. certificate 的结构约束是否在数值上真实生效，以及有界门控对局部可逆性有何影响。

所有变体使用同一份冻结的 R5 train/validation/test 数据、同一组网格
`n = 31, 63, 127`、同一组随机种子 `501, 502, 503, 504`，训练预算为每个模型 150 个
epoch。每个网格选择 validation 校正损失最低的 seed，再在最多 48 个 test case 和 12 个
确定性正弦噪声 case 上回放。

## 变体

| 变体 | 改动 | 用途 |
|---|---|---|
| `full` | 固定增益 `0.02`、状态质量范数、受约束 certificate | 主比较项 |
| `no_fixed_gain` | 去掉固定增益，校正网络承担全部注入 | 检查物理安全兜底的贡献 |
| `no_state_conditioning` | 去掉估计场质量范数输入 | 检查状态条件化的贡献 |
| `no_certificate` | certificate 退化为恒等映射 | 检查 certificate 是否影响当前在线管线 |
| `no_direction_constraint` | 使用无零空间约束的 certificate | 检查观测方向保持约束 |
| `no_lipschitz_control` | 保留零空间形式但去掉有界 `tanh` 门控 | 检查门控对局部可逆性的影响 |

其中 certificate 仍是离线分支，不进入部署时的观测器右端项。因此，如果不同 certificate
变体的在线误差完全一致，这不是实验失败，而是说明当前 R5-E 实现中的 certificate 还没有
与在线校正形成真正的训练耦合；这会作为结构性结果单独报告，不能包装成 certificate
带来了在线收益。

## 审计量

每个被选中的模型记录：

- test 和测量噪声下的终端误差质量中位数；
- `T(u,0)=0` 的零纤维残差；
- `C T(u,e)=C e` 的观测方向残差；
- 误差方向 Jacobian 的最小/最大奇异值。

本实验是有限样本、有限网格的消融，不推出连续空间全局稳定性或 certificate 的定理性质。
