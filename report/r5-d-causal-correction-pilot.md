# R5-D：在线校正本机留出实验

## 结论

R5-D 的本机留出实验通过了信息约束和数值稳定性检查，但没有超过经典固定增益基线。
带固定物理校正兜底的学习残差优于开环观察器，仍略逊于固定增益 `0.10`。因此当前证据支持
“学习残差可以作为合法的在线补偿项”，不支持“学习校正已经优于经典方法”。

## 实验设置

- 网格：`n=31`；Allen–Cahn 参数：`nu ∈ {0.005, 0.01, 0.02}`。
- 传感器：固定物理区间 `[0.20, 0.30]`、`[0.65, 0.75]` 的局部平均。
- 训练：R5 固定训练划分中 96 个 `n=31` case，4,896 个时间样本。
- 验证：R5 固定验证划分中 48 个 `n=31` case；训练和验证不重叠。
- 在线输入：当前估计、当前局部平均观测、已知网格和 `nu`；不输入真值或真误差。
- 对照：开环、固定增益 `0.02`、固定增益 `0.10`。
- 噪声检查：共同正弦测量噪声，幅值 `0.01`。

训练时使用真值只生成离线目标 `F(u)-F(estimate)`；部署滚动时只调用当前估计和当前观测。
学习项采用当前创新及其估计场质量范数的乘积，另保留固定物理增益项作为安全兜底。

## 验证集结果

| 方法 | 终点误差质量范数中位数 | 峰值误差质量范数中位数 | 共同正弦噪声下终点误差中位数 |
|---|---:|---:|---:|
| 开环 | 0.08681 | 0.10671 | 0.08681 |
| 固定增益 0.02 | 0.08374 | 0.10671 | 0.08373 |
| 固定增益 0.10 | 0.07196 | 0.10671 | 0.07190 |
| 学习残差 + 固定增益 0.02 | 0.07537 | 0.10671 | 0.07552 |

学习残差在 48 个验证 case 中有 87.5% 的终点误差低于开环，但固定增益 `0.10` 仍然最好。
所有方法在该组短时滚动中的观测器能量正增量缺陷中位数为 `0`；这只是本次离散轨迹诊断，
不是非线性稳定性定理。

```bash
.venv/bin/python tool/r5_causal_correction_smoke.py \
  --grid-size 31 --train-limit 96 --validation-limit 48 \
  --output out/2026-08-22-r5-d-causal-correction-smoke/results.json
```

原始 JSON 输出位于上述 `out/` 路径；`out/` 按规范不纳入 Git。
