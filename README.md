# Allen-Cahn Sensor Injection Certificate

研究传感器数量、观测几何和一般观测注入矩阵对 Allen--Cahn 观测器稳定证书的影响。

## 入口

- `design/`：实验方案与配置
- `src/`：正式实现
- `tests/`：正式测试
- `data/`：数据与来源说明
- `out/`：原始运行输出
- `report/`：整理后的分析与结论
- `tool/`：实验辅助工具

本仓库从原综合实验的 `codex/r5-oblique-injection-certificate` 路线独立出来；来源和冻结提交见
`docs/source-provenance.md`。
